## Featured Projects

### 🏗️ EAM Asset Template System

**Salesforce DX · Apex · Lightning Web Components · SOQL · Flow**

A configurable asset-template module built for enterprise asset management, modelling reusable asset definitions and maintenance-ready asset records.

- Custom `AssetTemplate__c` object with asset extensions covering hierarchy and versioning, maintenance tracking, technical specifications and financial data
- Service-layer Apex with a dedicated trigger handler and unit test coverage
- Lightning Web Component (`assetTemplateGenerator`) for template-driven asset creation
- Enhanced Lightning record pages, desktop and mobile layouts, compact layout and mobile quick actions
- Formula-driven fields for maintenance due dates and warranty state, keeping logic declarative where it belongs

> 🔒 Private repository (company assessment) — architecture walkthrough available on request.

**Django · Python · JavaScript · Tailwind CSS · Render**

A Django platform for a music composer company, built as a digital stage for artists, albums and media.

- Branded homepage layout with embedded music and video content
- Artist and album pages with a clean, responsive interface
- Deployed and maintained as a live public demo

🔗 [Repository](https://github.com/Vivekroy286/Unicon) &nbsp;·&nbsp; 🌐 [Live Demo](https://unicon-0t5q.onrender.com/)

### 🎥 Vchat — Multi-Peer Video Conferencing

**Django Channels · WebSockets · WebRTC · React · Python**

- Peer-to-peer video with screen and display streaming
- Real-time text chat with typing indicators and session message history
- Simple username-based joining flow for frictionless demos

🔗 [Repository](https://github.com/Vivekroy286/demochat) &nbsp;·&nbsp; 🌐 [Live Demo](https://vchat-990c.onrender.com/)

### 💬 ClineSolutions — Q&A Platform

A functional Quora-style platform where users post questions, share answers and discover content through a clean, user-engaging interface.

- Full question-and-answer workflow backed by Django models and views

- Emphasis on a working end-to-end system rather than a template mock-up
